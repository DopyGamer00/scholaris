##  Cadre de travail collectif

### Comment on prend des decisions
- **Decisions simples** (un texte, une couleur) --> le membre responsable décide seul
- **Décisions importantes** (structure du site, changement de tech) --> on vote en groupe
- **Desaccord** --> on presente chaque avis, puis on vote. Baba a le mot final

### Comment on communique
- **Canal principal :** Groupe WhatsApp "ScholarISI Team" 
- **Delai de reponse attendu :** 2h maximum en journee
- **Reunions :** 2 fois par semaine minimum (presentiel ou appel souvent apple et message)
- **Partage de fichiers :** uniquement via GitHub (pas d'envoi par email ou USB)
- **Blocage :** --> prevenir Baba immediatement, pas a la dernière minute

### Comment on valide le travail
1. Chaque membre teste son propre travail avant de le pousser
2. Un commit = une tache precise ( parfois difficiles a respecter )
3. Format du message : `[Prenom] - Description courte`
4. Baba verifie les ajouts majeurs avant soumission finale

---

##  Regles communes (acceptees par toute l'équipe)

- On respecte les delais fixes ensemble
- On communique les problemes dès qu'ils apparaissent
- On s'entraide : personne ne reste bloque seul ( c'est notre atouts seule ) 
- On reste professionnel, meme entre amis
