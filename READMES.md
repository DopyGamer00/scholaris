##  Lancer le projet (avec MySQL)

### Prerequis : XAMPP avec Apache + MySQL

**1. Copier le projet dans htdocs**
```
C:\xampp\htdocs\scholaris\   <--- coller tout le contenu de site/ ici
```

**2. Lancer XAMPP**
- Ouvrir XAMPP Control Panel
- Cliquer **Start** sur **Apache**
- Cliquer **Start** sur **MySQL**

**3. Verifier le port MySQL**
- Dans XAMPP --> Config --> my.ini --> chercher `port=3307`
- Si c'est un autre port, modifier `database/config.php`

**4. Ouvrir le site**
```
http://localhost/scholaris/index.html
```

**5. Dashboard admin (Baba)**
```
http://localhost/scholaris/admin/dashboard.html
```
